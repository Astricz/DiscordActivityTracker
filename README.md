# DiscordActivityTracker

A BetterDiscord plugin that tracks Discord user activity over time.

It logs online status changes, game activity, custom statuses, usernames, and avatars so you can view patterns like when someone is usually online.

## What it does

- Tracks user status changes (online / idle / dnd / offline)
- Logs game and app activity with session duration
- Stores custom status changes (text + emoji)
- Keeps username history
- Tracks avatar changes
- Shows basic analytics (peak hours, sessions, online rate, etc.)
- Lets you export all data as JSON
- Works per-user (you choose who to track)

Everything is stored locally through BetterDiscord.

---

## Installation

1. Install BetterDiscord
2. Download the plugin file
3. Move it into: %appdata%\BetterDiscord\plugins
4. Enable it in BetterDiscord settings

---

## How to use

- Right click a user → **Track Activity**
- Click the 👁 icon in the top bar to open the tracker
- Click a user in the list to expand their data

Inside the panel you can:
- View logs and stats
- Sort users
- Clear history
- Export data
- Remove tracking

---

## Data tracked

- Status history
- Activity sessions
- Custom status changes
- Username changes
- Avatar changes

---

## Notes

- Nothing is sent anywhere — everything stays on your PC
- Only users you manually select are tracked
- Requires BetterDiscord
